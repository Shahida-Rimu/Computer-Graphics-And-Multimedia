# Computer Graphics and Multimedia 

Welcome to the **Computer Graphics and Multimedia** repository! This space contains my academic lab assignments and projects focused on rendering 2D/3D graphics, shape modeling, and basic animations.

##  Repository Contents
This repository is structured by lab assignments and specific graphics tasks. Some of the key projects include:

*   **Double Triangle Double Color:** Implementation of rendering multiple geometric shapes with distinct color properties.
*   **Obtuse Triangle and Rectangle:** Core 2D shape drawing and coordinate mapping.
*   **Red Triangle Spin (Lab 4):** Introduction to computer animation and transformations (rotation) using a spinning shape.

##  Concepts Covered
*   Basic geometric primitives drawing (Lines, Triangles, Rectangles)
*   Color interpolation and mapping
*   2D Transformations (Translation, Rotation, Scaling)
*   Animation basics in graphics programming
